# Security policy

## Reporting a vulnerability

Please do **not** open a public issue. Use **Report a vulnerability** on the Security tab of this
repository (private vulnerability reporting), with:

- what you found and where (URL, file, request),
- steps to reproduce,
- the impact you expect.

You will get an answer within 7 days. Please give us 30 days to fix the issue before you publish it.

## Supported versions

Only the latest version on `main` receives security fixes.
